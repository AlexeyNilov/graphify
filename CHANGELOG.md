# Changelog

## 1.0.1

- Added explicit `OPENAI_API_KEY`, `OPENAI_BASE_URL`, and `OPENAI_MODEL` support.
- Switched structured Markdown extraction to the LM Studio-compatible Chat Completions endpoint.

## 1.0.0

- Replaced general code analysis with a corporate architecture graph pipeline.
- Added deterministic OpenAPI 3.x extraction.
- Limited semantic Markdown extraction to OpenAI.
- Added stable architecture entity IDs, aliases, confidence, and provenance.
- Reduced the CLI to build, query, path, affected, inspect, and Codex installation commands.
- Removed unrelated providers, assistants, inputs, exports, databases, and workflow integrations.
